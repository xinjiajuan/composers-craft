# 游戏音乐案例与作曲方法

按创作问题选择案例，将作品或场景中的设计思路迁移到新的音乐。每例包含目标、操作步骤和检查方式；示例方案中的音符、轨道划分与参数应按当前项目设计。

## 案例选择

| 案例 | 作品或场景参照 | 要解决的问题 | 核心方法 |
|---|---|---|---|
| G01 | 《原神》桑多涅：机械感与坦率化 | 同一角色如何表现不同心理状态 | 即兴筛选、音型塑造、大跳与级进、主题变形 |
| G02 | 桑多涅的回忆情境与莫扎特 K.466 主题联想 | 如何让音乐素材承担叙事意义 | 素材积累、情境匹配、主题整合 |
| G03 | 角色在钢琴前的固定演出 | 如何安排完整的戏剧发展 | A–B–A、对比与回归、自由速度 |
| G04 | 《八方旅人》式的互动音乐体验 | 如何自然地进入和退出段落 | 和声出口、过渡句、播放同步 |
| G05 | 《原神》国际象棋意象的王后战 | 如何让音乐直接反映战况 | 角色声部进退、织体变化、狂暴段升级与收束 |
| G06 | 《原神》《八奇炼桃都》相关戏曲唱段 | 如何融合唱腔、歌词与戏剧任务 | 原创与传统素材分工、依词写曲、试唱修订 |
| G07 | 《原神》的管弦乐表达 | 如何用管弦音色实现清楚的表达 | 风格与编制分开设计、声部功能与平衡 |

## G01：让角色主题随心理状态改变

**创作目标。**一个机械木偶般、言语曲折的角色，逐渐显露坦率的一面。两个状态需要有不同感受，同时让听者认出同一个角色。

**做法。**

1. 试弹几个短动机，比较大跳、停顿和不规则重音是否支持机械感与曲折感，保留最有辨识度的材料。
2. 提取主题的节奏、关键落音或轮廓，确定变形时应保留的特征。
3. 在坦率化的版本中收拢部分跨度，增加级进或连贯的乐句，再通过模进继续发展。
4. 另作一轮和声与配器比较，决定是否保留神秘色彩、减少紧张或改变音区。

**检查。**用相同音色、力度与速度比较两个动机，确认听感变化来自写法。若认不出主题，恢复一个辨识点；若仍无状态差别，换一个变化维度。音程与性格的联系需在场景中成立，不能仅凭“大跳”或“级进”命名情绪。

**可交付内容。**两个主题版本、保留与变化清单，以及每项改变的表达理由。音符示例见 [练习一与练习四](practice-patterns.md)。

## G02：让已有音乐意象找到合适的戏剧情境

**创作目标。**为回忆、牺牲或人物关系变化选择有内在联系的材料。桑多涅的回忆情境与 K.466 主题的联想可作为思考起点；具体作品只是素材选择的一种可能。

**做法。**

1. 保存素材的节奏、音程、句法、音色或和声特征，记录自己的听感与可能对应的戏剧动作。
2. 对照当前创作简报，判断素材支持的是回忆、告别、坚定还是其他含义，并说明理由。
3. 若需要与已有角色主题结合，明确连接点：共享节奏、轮廓、关键音或和声背景。
4. 区分直接引用、改写与仅借用组织方法。需要使用现成旋律时，明确所用材料与改写范围。

**检查。**去掉作品名称后，能否仍说明这段材料为什么适合场景？联系不成立时换材料，不以熟悉度代替叙事理由。

**可交付内容。**素材特征笔记、情境匹配理由和一个可演奏的整合草稿。

## G03：为固定演出安排完整曲式

**创作目标。**角色坐在钢琴前演奏，画面配合音乐的既定发展，音乐可以完整表达人物的不同侧面。

**做法。**

1. 确认演出时长、画面动作和是否允许中断。
2. 用 A 呈示人物基调，B 提供另一面或冲突，再让 A 回归；说明回归是否改变和声、音区、力度或句尾。
3. 在乐句层面安排呼吸、rubato 和到达点，让演奏的伸缩服务于结构。
4. 若同一主题还要用于探索或战斗，另外设计可循环、可等待和可退出的版本。

**检查。**段落对比是否清楚，回归是否有意义，音乐与动作是否互相支撑。互动版本应单独检查同步和出口。

**可交付内容。**曲式图、段落功能、演奏处理和需要适配的循环版本。

## G04：为互动音乐写好进入与离开的方式

**创作目标。**以《八方旅人》式的连贯互动体验为参照，让不确定时刻发生的状态切换仍具有音乐句法。下面给出可用于自己项目的设计方法。

**做法。**

1. 列出循环段的和声位置、允许出口及目标段入口。
2. 为不同出口准备可以接上的过渡或终止句；和声、旋律尾音与目标一致时考虑复用。
3. 规定切换需求如何等待音乐拍点，以及过渡后从目标段的哪个位置进入。
4. 处理声音尾部、短暂等待与可能的重复触发。

**检查。**逐个触发实际可达的出口，听拍点、和声、句法与尾音是否连贯。不同出口需要多少素材由音乐结构决定，无需穷举不会出现的状态。

**可交付内容。**入口与出口表、过渡素材清单和触发规则。具体字段见 [互动配乐设计](interactive-music.md)。

## G05：把双角色战斗机制写进音乐声部

**创作目标。**以王与后的双角色战斗为例，让听者从声部的存在、缺席和变化中感到战况。

### 声部与角色状态对应

分别为两名角色设计可辨认的声部，合奏时安排对唱、齐唱或复调关系。角色倒下时对应声部退出，复起后重新加入；需要保留的和声支撑另行分配。

| 战斗状态 | 音乐设计 |
|---|---|
| 两名角色均在场 | 两个角色声部形成对答或合奏 |
| 一名角色暂时倒下 | 其声部退出，另一声部及必要支撑继续 |
| 角色复起 | 在适合的拍点或乐句入口重新加入 |
| 只剩一名角色并升级状态 | 改变现存材料的音高层次、织体或和声张力 |

### 升级状态也要准备收束

可尝试将材料按大三度上移以改变音高层次，同时另行设计和声连接与落点。若使用减七等音重释，写出和弦音和各声部去向；移高材料和解释减七功能是两项不同操作。

**检查。**两个角色声部分别单独存在时是否仍成立，回归时是否同步，升级段能否在允许位置自然收束。不要把关键低音或必要支撑全部放在可随时关闭的轨道里。

**可交付内容。**角色轨道设计、组合表、进入退出规则、升级段及过渡。减七解决的音符练习见 [练习五](practice-patterns.md)。

## G06：让戏曲唱段同时满足歌词与戏剧任务

**创作目标。**以《八奇炼桃都》相关唱段为参照，在角色叙事中组织原创旋律、传统戏曲素材与歌词表达。

**做法。**

1. 确认唱段的戏剧动作、长度和必须突出的歌词。
2. 选择所需的唱腔基础与融合方向，例如河北梆子、昆曲或京剧中的具体旋律和行腔特征，避免只依靠乐器音色表示风格。
3. 若采用西皮流水等传统素材，分别标明素材、填词、改写和原创段落的范围。
4. 先念歌词再写旋律，检查重音、声调走向和关键字的可懂度。
5. 通过试唱修订倒字、咬字或行腔不自然的地方；不熟悉的语言和剧种交由熟悉者核验。

**检查。**不看文字是否仍能听懂重点歌词，旋律是否符合所选风格，融合是否有具体依据。声调与歌唱的关系应结合语言和唱腔处理，不机械逐点复制说话的音高曲线。

**可交付内容。**唱段结构、歌词重点、旋律草稿、素材分工及试唱修订记录。

## G07：用管弦乐编制实现清楚的音乐表达

**创作目标。**以《原神》中的管弦乐表达为参照，在保持旋律清楚、结构可感的同时，利用丰富音色塑造层次。

**做法。**

1. 先确定音乐语言与结构，再选编制；使用管弦乐队不自动限定曲式或和声风格。
2. 完成主旋律、低音与基本和声，明确各声部承担的作用。
3. 将旋律、和声支撑、节奏和对位分配到合适的乐器、音区与力度层次。
4. 主旋律不清楚时，先检查同音区的密度、持续时间、音色与力度，再选择改配器或混音处理。

**检查。**较少声部时的主题是否成立，增加乐器后是否更好地服务于目标，每个声部是否都有保留理由。不要用更厚的织体掩盖不明确的旋律与结构。

**可交付内容。**段落配器表、主次关系与修改前后的比较。练习见 [练习六](practice-patterns.md)。

## 通用场景：战斗强度的分层变化

用稀疏节奏或氛围提示潜在危险，战斗升级时加入低音、和声、主题或对位，强烈状态再加入强调声部。让每个允许的组合都成立，明确加入与退出的音乐位置。

状态变化既可以通过层的增减实现，也可以通过换段实现。先确定要改变的是密度、旋律内容、和声张力还是结构，再选择控制方式，避免所有状态都只改变音量。
