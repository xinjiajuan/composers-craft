# The Composer's Craft

用于作曲、编曲与游戏配乐设计的 AI skill。把情绪、角色、场景或玩法需求转化为旋律动机、和声、低音、曲式和配器方案，提供可演奏的文字草稿与试听比较方法。

## 适用任务

- **主题创作与变奏**：设计短动机，让同一主题表达角色的不同状态，同时保留辨识点。
- **和声与低音**：为已有旋律配和声，组织转位低音、声部连接和转调。
- **曲式与配器**：安排段落对比与回归，分配旋律、和声、节奏、低音和对位声部。
- **互动游戏音乐**：根据项目中的状态变化，设计音乐循环、分层，以及段落入口、出口和过渡。
- **戏曲唱段与练习**：处理歌词重音、声调与行腔，通过短小谱例比较不同写法。

## 使用方式

技能入口为仓库根目录的 [SKILL.md](SKILL.md)。安装时保留整个 `composers-craft` 目录及其中的 `references/`，放入所用客户端支持的技能目录。安装位置与调用方式由客户端决定。

在 Codex 中可通过 `$composers-craft` 调用；其他 Agent 使用各自的技能调用方式。对于支持文件读取、但没有技能发现功能的 Agent，可以要求它先读取 `SKILL.md`，再按任务需要读取其中链接的参考文档。

从自己的创作目标与已有材料出发，说明用途、目标感受、时长和乐器条件，再选择适合的方法。涉及互动配乐时，补充项目实际的触发事件、循环需求及允许切换的位置。尚未确定的调性、速度或编制，可以让助手提出工作假设。

为已有旋律配和声时，请提供实际音高与时值，例如乐谱、MIDI 或注明节奏的音名。

### 提问模板

```text
请使用 composers-craft 技能帮我完成以下创作任务：
用途：[这段音乐在我的作品或项目中承担什么作用]
目标：[希望表达的内容，或当前需要解决的音乐问题]
已有材料：[旋律、节奏、和弦、歌词或文件；没有则说明]
创作条件：[时长、乐器、演奏或制作条件，以及需要保留的内容]
希望得到：[音乐草稿、修改建议、比较方案或练习]
```

## 交付内容

根据任务规模提供：

- 创作意图，以及旋律、和声、音色或结构选择的理由。
- 以小节、拍位、音名、八度和时值表达的草稿；需要时附和弦、转位与低音。
- 曲式与配器安排，或互动音乐的状态、轨道组合和过渡规则。
- 一项可通过演奏或 DAW 回放验证的对比，以及可调整的方向。

谱例文件、MIDI 或音频的生成取决于当前工具条件。文本草稿需要实际试听；互动方案接入引擎或中间件后，还需验证循环、同步和过渡效果。
