# 至冬堡夜晚主题曲《琴弦呀，琴弦》：人工鉴赏、录音实测与钢琴扒谱复核

这份报告记录案例 G09 和练习二十一至二十五的来源与判断边界。能单独使用的技能入口是仓库根目录的 `SKILL.md`，技能正文和参考文件都不依赖这份报告。

## 来源与读法

- 原曲是《原神》至冬堡（至冬国主城）夜晚的大世界背景音乐《琴弦呀，琴弦》（O Strings, My Strings），HOYO-MiX 出品，收在专辑《悯宥慈怜之垠》，歌词是俄语。播放器上的制作名单：作词项柳、Nikolai Novichkov，作曲、编曲姜以君，伦敦交响乐团演奏，Robert Ziegler 指挥，Genshin Choir 合唱，录音在 AIR Lyndhurst Hall 和 Largo Studio。
- 人工鉴赏用的是 B 站 up 主雨后的晚星《音乐Re》系列的一期（25:47，没有字幕）。乐器、人声、性格以它为准。
- 委托方听过原曲，补充了三点：人声有女声、男声、男女混声三种合唱；斯拉夫、苏联歌曲的味道被游戏大世界的风格包住；鉴赏者说的轮唱在副歌二。
- 钢琴扒谱版是 B 站 up 主猫与特调酒的“高还原改编·纯钢琴”，和《寂夜月如锋》钢琴版出自同一位扒谱者：
  - 和原版一小节对一小节，速度一样，固定时差 0.807 秒；
  - 音高、和声、结构当原曲缩谱读，旋律是扒谱者听写的；
  - 第 1 小节的弱起和弦是扒谱者加的，原版那里没有声音；
  - 画面上没有力度和踏板。
- 原版录音是 B 站上传者 JLRS-jayfm 的“百万级录音棚试听”，画面底部有俄语歌词字幕，歌词时间以它为准。

## 怎么核对

- 鉴赏视频没有字幕：
  - Gemini 分两遍转写，每段 100 秒，两遍错开 50 秒，31 段全部转出，按句子对齐拼成全文；
  - 拿不准的词截 20～35 秒单独复听，三遍按多数记（“C 调”“白沙皇”）；
  - 画面每秒读一帧，看播放器停在曲子哪里、歌词面板上光标指着哪句，念歌词时由此知道念的是哪一句；
  - 整段视频和原曲逐秒比对（白化的对数梅尔谱），找出哪几段在放原曲。色度比对把插进来的《保卫黄河》误配成原曲 5 秒，换成这个方法后排除了。
- 钢琴扒谱版逐帧读 88 键（1080p、30 帧，按下的白键变成淡紫蓝），得到 1477 个音；全曲严格 130.01 BPM、4/4；每小节音级分布与音频色度的相关，中位 0.91。
- 原版录音按段量了 K 加权响度、频段占比和打击成分；按扒谱的旋律量了旋律音在各个八度上比周围突出多少，用来判断男声在不在；副歌二的高声部用同样的方法逐小节量。
- Gemini 分段、分短片段听了原版 16 次，只采纳和实测或人工鉴赏对得上的内容。

## 逐项结果

| 项目 | 结果 | 能确认到什么程度 |
|---|---|---|
| 结构 | 前奏 8 小节（加弱起）、主歌一 16、主歌二 16、间奏 16、副歌一 16、副歌二 16、收尾句 2、散板尾奏 | 扒谱与录音一致；鉴赏者也说结构好分 |
| 主题预告 | 前奏（D 小调）和间奏两遍（F 小调）都是副歌旋律的前 6 小节，最后停在属和弦；主音 D、F、G 一次比一次高 | 扒谱逐小节比级数；鉴赏者说“前奏是把高潮的旋律简化放在开头” |
| 三套和声 | 持续低音上一级级往下；五度循环；主歌的进行（和主歌一的相似度 0.80，和副歌一 0.36） | 扒谱，四小节窗口比对 |
| 调性 | D 小调 → C 小调 → F 小调 → G 小调；导音只在换调处；间奏的枢纽是 B♭ 大三 | 扒谱，几处用原版色度核对 |
| 自由模退 | 副歌骨架 5–4–4–3–3–2–1，长音加下行和两音来回交替 | 扒谱；“自由模退”这个名称和“光明的向下”是鉴赏者的说法 |
| 人声 | 主歌一女声（低八度没有基频，−1.6 dB）、主歌二男声（+5.3 dB）、副歌混声 | 委托方与鉴赏者一致，实测作旁证 |
| 轮唱 | 副歌二每两小节的后一小节，高声部比主旋律早半拍、高三度唱同样的下行（+5.4～+6.8 dB，副歌一同位置 −3.0～+0.9）；主旋律原八度变弱，低八度还在 | 位置由委托方确认；形式来自实测；隔半句的严格卡农没量到 |
| 乐器 | 人声第一；钢琴全场都有；管风琴在间奏和副歌；弦乐；前奏开头是竖琴 | 鉴赏者；实测分不出乐器 |
| 动态 | −25.7 → −9.2 LUFS，只在间奏前半回落一次；间奏后半 +4.9 dB；结尾两秒多掉 12 dB | 原版录音实测 |
| 打击 | 打击成分 3%～8%，没有反拍，也没有固定的底鼓型 | 实测 |
| 风格 | 斯拉夫、苏联歌曲的语汇被大世界的管弦包住 | 委托方；具体是哪些语汇是分析判断 |
| 性格 | 叙事曲；女声倾诉、男声拷问；副歌升华；最后一段像“灵魂的风” | 鉴赏者 |

## 初判被人工鉴赏更正的地方

- 主歌一写成“女声独唱”：委托方说是合唱，三种合唱都有。
- 前奏和结尾的弹拨乐器写成吉他，还由此联想到俄罗斯浪漫曲用吉他伴奏：鉴赏者听出前奏开头是竖琴。
- 漏了钢琴和管风琴：鉴赏者说钢琴全场都有，管风琴是除人声外最打动人的音色。
- 副歌二的高变体，初稿猜是小提琴加的：鉴赏者说是男女轮唱，委托方确认了位置，实测是一条人声高声部。

## 未采纳的 Gemini 内容

- 前奏、主歌、结尾都说有吉他：鉴赏者听出前奏开头是竖琴。
- 间奏后半底鼓打一、三拍、铃鼓打二、四拍，还有电贝斯、电吉他、架子鼓：打击成分实测不支持。
- 把副歌认成一首具体的苏联歌曲，还写出那首歌的歌词：委托方说只对了风格。
- 一次说副歌是 C 小调，实际是 G 小调。
- 男声、女声、独唱、合唱，前后说法互相矛盾。
- 原曲四个片段里都说“听不出钢琴”，和鉴赏者说的“钢琴全场都有”矛盾。
- 给扒谱试听挑钢琴音色时，盲听相似度选了明亮的三角钢琴；委托方听了更喜欢毡锤立式钢琴，嫌三角钢琴的低音糊。

## 技能里改了什么

1. 新加案例 G09：让一首合唱主题曲一路推到最后一遍，包括做法、配器、检查、交付和参照曲的具体材料。案例选择表与材料表同步更新。
2. `SKILL.md`：
   - 第 2 节加入主题先由乐器在升高的调上预告；
   - 第 3 节加入同一旋律整句换和声；
   - 第 4 节加入调性先沉后升，大三属和弦留给换调；
   - 第 5 节加入人声一段换一种编制、最后一遍错开半拍的同形声部、下行写得光明、两秒收尾。
3. 练习二十一至二十五：
   - 二十一：主题在升高的调上预告；
   - 二十二：同一旋律配三套和声；
   - 二十三：调性先沉后升；
   - 二十四：人声一段换一种编制；
   - 二十五：早半拍、高三度的同形声部，下行写得光明，两秒收尾。
4. 所有音名练习都是原创教学示例，不复现原曲旋律；歌词不抄原文，只写大意。
5. `readme.md` 的适用任务加了一条。
