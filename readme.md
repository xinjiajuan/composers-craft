# The Composer's Craft

用于作曲、编曲和游戏配乐设计的 AI skill。它把情绪、角色、场景或玩法需求写成旋律动机、和声、低音、曲式和配器方案，给出能演奏的文字草稿，并说明怎样试听比较。

## 适用任务

- 设计短动机，让同一个主题在变奏中表现角色的不同状态，同时保留辨识点。
- 给已有旋律配和声，组织转位低音、声部连接和转调。
- 安排段落的对比与回归，分配旋律、和声、节奏、低音和对位声部。
- 按项目里的状态变化，设计互动游戏音乐的循环、分层，以及段落的入口、出口和过渡。
- 安排一首有合唱的主题曲，从器乐预告主题一直写到最后一遍合唱。
- 写一首安静的场景曲：一组固定音型从头撑到尾，人声和鼓留到最后一段。
- 处理戏曲唱段的歌词重音、声调与行腔；用短小的谱例做练习，比较不同写法。

## 使用方式

技能入口是仓库根目录的 [SKILL.md](SKILL.md)。安装时保留整个 `composers-craft` 目录和里面的 `references/`，放进所用客户端支持的技能目录。装在哪里、怎样调用，由客户端决定。

在 Codex 里可以用 `$composers-craft` 调用；其他 Agent 按各自的方式调用技能。有的 Agent 能读文件、却没有技能发现功能，可以让它先读 `SKILL.md`，再按任务需要读其中链接的参考文档。

使用时从自己的创作目标和已有材料说起，讲清用途、目标感受、时长和乐器条件，再选合适的方法。涉及互动配乐时，再补上项目里实际的触发事件、循环需求和允许切换的位置。调性、速度或编制还没定的，可以让助手先提出工作假设。

为已有旋律配和声时，请提供实际的音高和时值，比如乐谱、MIDI 或注明了节奏的音名。

### 提问模板

```text
请使用 composers-craft 技能帮我完成以下创作任务：
用途：[这段音乐在我的作品或项目中承担什么作用]
目标：[希望表达的内容，或当前需要解决的音乐问题]
已有材料：[旋律、节奏、和弦、歌词或文件；没有则说明]
创作条件：[时长、乐器、演奏或制作条件，以及需要保留的内容]
希望得到：[音乐草稿、修改建议、比较方案或练习]
```

## 交付内容

按任务规模交付：

- 创作意图，以及旋律、和声、音色或结构为什么这样选。
- 用小节、拍位、音名、八度和时值写出的草稿；需要时附上和弦、转位和低音。
- 曲式与配器安排，或者互动音乐的状态、轨道组合和过渡规则。
- 一项能用演奏或 DAW 回放来验证的对比，以及可以调整的方向。

能不能生成谱例文件、MIDI 或音频，要看当时的工具条件。文本草稿需要实际试听；互动方案接入引擎或中间件后，还要验证循环、同步和过渡效果。
