# 游戏音乐案例与作曲方法

按创作问题选择案例，将作品或场景中的设计思路迁移到新的音乐。每例包含目标、操作步骤和检查方式；示例方案中的音符、轨道划分与参数应按当前项目设计。

案例编号按作曲问题划分。G01 与 G03 的角色都是《原神》桑多涅：G01 讨论心理状态与主题变形，G03 讨论她在钢琴前演出的曲式安排；G02 补充她的回忆情境与素材联想。G08 的参照是霜月战斗曲《寂夜月如锋》：段落、调性、性格与配器以一位 up 主的人工鉴赏为准，音高来自玩家扒谱的钢琴还原版，动态与频段来自原版录音的分段实测。G05 的参照是“门扉前的弈局”周本 Boss 战的三首战斗曲：段落、出处、性格与交互以同一位 up 主的人工鉴赏为准，音高来自玩家钢琴改编版的前半，配器与动态来自原版录音的分段实测。

## G01：让角色主题随心理状态改变

**创作目标。**以桑多涅初登场的阴森纯钢琴主题与后来的光明版本为例，表现她机械木偶般、言语曲折的状态，以及逐渐显露的坦率一面。两个版本需要有不同感受，同时让听者认出同一个角色。

**做法。**

1. 试弹几个短动机，比较大跳、停顿和不规则重音是否支持机械感与曲折感，保留最有辨识度的材料。
2. 提取主题的节奏、关键落音或轮廓，确定变形时应保留的特征。
3. 在坦率化的版本中收拢部分跨度，增加级进或连贯的乐句，再通过模进继续发展。把“改变轮廓”和“把片段在不同音级上展开”分成两轮操作，分别保留可比较的版本。
4. 另作一轮和声与配器比较，决定是否保留神秘色彩、减少紧张或改变音区。

**检查。**用相同音色、力度与速度比较两个动机，确认听感变化来自写法。若认不出主题，恢复一个辨识点；若仍无状态差别，换一个变化维度。音程与性格的联系需在场景中成立，不能仅凭“大跳”或“级进”命名情绪。

**可交付内容。**两个主题版本、保留与变化清单，以及每项改变的表达理由。音符示例见 [练习一与练习四](practice-patterns.md)。

**具体材料与场景。**关注同一主题在机械、曲折与临终坦率、回忆状态中的变形。大跳是旋律轮廓，增减音程是和声或音程色彩，两者可分别调整；不能只靠换“温柔音色”完成主题变形。模进的可演奏步骤见 [练习七](practice-patterns.md)。

## G02：让已有音乐意象找到合适的戏剧情境

**创作目标。**为回忆、牺牲或人物关系变化选择有内在联系的材料。桑多涅的回忆情境与 K.466 主题的联想可作为思考起点；具体作品只是素材选择的一种可能。

**做法。**

1. 保存素材的节奏、音程、句法、音色或和声特征，记录自己的听感与可能对应的戏剧动作。
2. 对照当前创作简报，判断素材支持的是回忆、告别、坚定还是其他含义，并说明理由。
3. 若需要与已有角色主题结合，明确连接点：共享节奏、轮廓、关键音或和声背景。
4. 区分直接引用、改写与仅借用组织方法。需要使用现成旋律时，明确所用材料与改写范围。

**检查。**去掉作品名称后，能否仍说明这段材料为什么适合场景？联系不成立时换材料，不以熟悉度代替叙事理由。

**可交付内容。**素材特征笔记、情境匹配理由和一个可演奏的整合草稿。

**具体材料与场景。**K.466 是莫扎特《第20号 d 小调钢琴协奏曲》的作品编号，编号本身不能确定乐章或旋律片段。素材卡应记录“乐章／主题、节奏与音程特征、预期场景、与角色主题的连接点”。用于牺牲与走马灯式回忆时，先判断需要纤细的个人叙述还是宏大的英雄表达，再决定配器规模；保留主题身份与叙事功能的联系。

## G03：为桑多涅的钢琴演出安排完整曲式

**创作目标。**与 G01 同一角色的桑多涅来到钢琴前，触发一段固定演出。这里的动画动作按既定乐曲制作，演出当时不能跳过，也不随玩家的随机行动切换音乐，因此可以安排完整的单三部曲式与自由速度，表达她的不同侧面。

**做法。**

1. 区分玩家触发演出与演出中持续改变音乐的行为，再确认演出时长、画面动作和是否允许中断。
2. 用 A–B–A 组织单三部曲式。桑多涅的例子以前后段的善意与中段的阴森形成对比；用于新作品时，明确各段表达哪一面，以及回归是否改变和声、音区、力度或句尾。
3. 在乐句层面安排呼吸、rubato 和到达点，让演奏的伸缩服务于结构。
4. 若同一主题还要用于探索或战斗，另外设计可循环、可等待和可退出的版本。

**检查。**段落对比是否清楚，回归是否有意义，音乐与动作是否互相支撑。互动版本应单独检查同步和出口。

**可交付内容。**曲式图、段落功能、演奏处理和需要适配的循环版本。

## G04：为互动音乐写好进入与离开的方式

**创作目标。**以《八方旅人》式的连贯互动体验为参照，让不确定时刻发生的状态切换仍具有音乐句法。下面给出可用于自己项目的设计方法。

**做法。**

1. 列出循环段的和声位置、允许出口及目标段入口。
2. 为不同出口准备可以接上的过渡或终止句；和声、旋律尾音与目标一致时考虑复用。
3. 规定切换需求如何等待音乐拍点，以及过渡后从目标段的哪个位置进入。
4. 处理声音尾部、短暂等待与可能的重复触发。

**检查。**逐个触发实际可达的出口，听拍点、和声、句法与尾音是否连贯。不同出口需要多少素材由音乐结构决定，无需穷举不会出现的状态。

**可交付内容。**入口与出口表、过渡素材清单和触发规则。具体字段见 [互动配乐设计](interactive-music.md)。

**具体材料与场景。**这里处理的是“当前和弦位置 → 匹配的终止句 → 下一段入口”，而非任意时刻剪接成品音频。先写每个实际出口的短终止句，再检查哪些可以复用；[练习十](practice-patterns.md) 给出 Dm、Am 两个出口进入 C 的不同连接长度。

## G05：把双角色战斗机制写进音乐声部

**创作目标。**以王与后的双角色战斗为例，让听者从声部的存在、缺席和变化中感到战况。同一场战斗的三首曲子还示范了怎样用借用动机写出性格，以及循环、大招与残血时音乐怎样变，见下文“参照与读法”起的几节。

### 声部与角色状态对应

分别为两名角色设计可辨认的声部，合奏时安排对唱、齐唱或复调关系。角色倒下时对应声部退出，复起后重新加入；需要保留的和声支撑另行分配。

**具体材料与场景。**角色关系通过声乐声部的对答、共同发声和独立进行表现。王的笨重与后的灵活可指导音型和节奏比较，但不预设固定声种、速度或音域。先让两条线单独成立，再安排合唱关系；[练习九](practice-patterns.md) 给出完整两小节双声部及常驻低音。

| 战斗状态 | 音乐设计 |
|---|---|
| 两名角色均在场 | 两个角色声部形成对答或合奏 |
| 一名角色暂时倒下 | 其声部退出，另一声部及必要支撑继续 |
| 角色复起 | 在适合的拍点或乐句入口重新加入 |
| 只剩一名角色并升级状态 | 改变现存材料的音高层次、织体或和声张力 |

### 升级状态也要准备收束

可尝试将材料按大三度上移以改变音高层次，同时另行设计和声连接与落点。若使用减七等音重释，写出和弦音和各声部去向；移高材料和解释减七功能是两项不同操作。

**检查。**两个角色声部分别单独存在时是否仍成立，回归时是否同步，升级段能否在允许位置自然收束。不要把关键低音或必要支撑全部放在可随时关闭的轨道里。

**可交付内容。**角色轨道设计、组合表、进入退出规则、升级段及过渡。减七解决的音符练习见 [练习五](practice-patterns.md)。

大三度移高的实际音名、循环关系与音区上限见 [练习八](practice-patterns.md)。把持续升级和可随事件结束两项要求一起设计。

### 参照与读法

本案例的参照是《原神》“门扉前的弈局”周本 Boss 战：主角被变成小人，在棋盘上和国际象棋棋子打。第一场放《囿于棋格中》，Boss 是轮流出场的王棋与后棋；棋盘翻转后的第二场放《方寸颠倒》，拟人化的国王与王后同时在场；只剩一个敌人且血量很低时换成《累棋之危》。上面的声部进退取自第二场，以下补充三首曲子的写法、循环与事件规则。段落、动机出处、性格与交互以一位 up 主的人工鉴赏为准；音高来自玩家钢琴改编版的前半，后半是改编者自己写的；配器与响度来自原版录音的分段实测。录音把前两首前后接着放，两首之间的接缝不是作曲设计，不要当作阶段过渡来学。

### 用带含义的借用动机写出“诙谐的奇幻童话”

1. 借动机要带含义。三组材料各有来源，来源的含义对应场景（出处是鉴赏者的判断）：断奏的下行半音动机借鉴格里格《侏儒进行曲》（写山林里的小精灵），对应变小的主角和跳着走的棋子；游戏里魔女会的主题只取第一句再变奏，点明这场试炼与魔女会有关；循环前的一段借鉴普罗科菲耶夫《彼得与狼》中猫的主题，用交响童话突出童话感。每次只借一句或一个音型，借来就变奏、移调、换节奏。自己写时，优先引用本作品已有的势力或角色主题；借古典作品先确认已进入公有领域。
2. 用音程词汇区分材料。侏儒动机的最高声部一半以上是半音级进，加同音反复；魔女会的变奏几乎没有半音，大跳过半。听者凭“一步一步挪”还是“一跳一跳”就知道是哪组材料。
3. 一组材料共用一个节奏细胞。侏儒动机的几个部件——同音对半音下行、邻音回旋、一对对倚音往上爬——音高各不相同，都是“反拍起、正拍落”，散而不乱。
4. 每次重现上一个五度。侏儒动机依次落在 D 小调、A 小调、E 小调、B 小调，不写新旋律也能感到局势升级。
5. 最响的地方放一个两音固定音型。高音区两个音用十六分音符来回（参照曲是两组相差半音的三全音），底下钉住其中一个音当持续低音；鉴赏者把它比作《猫和老鼠》里吓得心脏要跳出来。原版录音里这是全曲最响的地方，钢琴改编版里同样的音却不比前后响：分量来自下面的低音、铺底与重击。
6. 进高潮用“踩空”。属和弦上冲音阶攒满张力，落点不解决，低音挪开三全音或半音进入固定音型。
7. 高潮后接单声部低谷。一对对半音沿和弦骨架挪的单线，或撤掉低音的抒情句，3～7 秒，换气，也把音区搬到下一段。
8. 用颜色跳换和演奏法做幽默。多种调式交替；一本正经的古典终止旁边紧挨着减七、增三这类对称和弦；乐器大多断奏、跳音，加滑音和高低音区的一问一答。鉴赏者认为一问一答代表轮流出场的王棋与后棋。
9. 对称五段加循环体。第一首是 A（侏儒）–B（魔女会）–C（魔女会变奏，音符密度放慢一倍）–B′（更密、更轻快）–A′，再接猫的主题。引子和第一个 A 只放一次，循环体从 B 开始；循环体结尾停在 B 那个调的属音持续低音上，跳回去就是属到主，循环点放在小节线上。第二首把同一套材料重排为 A–B–A′–B′，再写新旋律，首尾写成同一句，直接首尾相接。

### 大招、残血与换人：让音乐停下或换掉

除了声部进退，参照战斗还用整首音乐的停与换回应事件：

- **大招静音。**敌人放必杀技时，用降调音效把音乐停掉，只留王后的歌声。游戏提示玩家引诱国王的冲刺去打断她，她唱的这段时间就是应对窗口；音乐的安静把注意力全交给它。
- **残血换曲。**只剩一个敌人且血量很低时换成《累棋之危》：用侏儒动机模进成上行的一句，几个八度同时奏、音量交叉渐变（谢泼德音阶），听着一直在升却到不了顶；鉴赏者说它的音量是波浪式地渐强渐弱交替，不是单向的。它和上文按大三度移高是两种做法：连续移高总会撞到音区上限，八度分层的循环能让“在升”的感觉一直持续。两种都要能在战斗结束时收住。
- **按出场者切段**（鉴赏者的设想，不是原曲做法）。第一场王棋与后棋轮流出场：后棋阶段渐弱换到更轻快的第二个 B 段并在那里循环，王棋阶段放开头到 C 段再接猫的主题。要这样做，得重写出口。

规则字段见 [互动配乐设计](interactive-music.md)，练习见 [练习十六至二十](practice-patterns.md)。

### 配器

以下来自原版录音的分段实测。

1. 不用二、四拍军鼓。第一首前一分钟只有均匀的八分音符脉动，十六分音符的高频层到 C 段才打开；第二首鼓型很平，靠人声和每 4 小节一记低频重击推进。
2. 超低频只在两段开：第一首循环前的猫的主题，第二首的第一个平台；其余段落几乎没有。
3. 第二首后段是“平台—回落—平台”：第一个平台加超低频；男女主唱前半撤掉超低频和低音，打击占比反而升高，变薄但不停；第二个平台把普通低音换回来，不再加超低频。
4. 进高潮、进平台前几拍让高频逐拍变亮，落点一记低频重击；进回落不铺垫，直接撤。
5. 换成人声领唱后整体变亮：1～4 kHz 的占比从第一首的两到三成，升到第二首的三到五成。

**补充检查。**每组借用材料单独弹，能不能一下认出；按最高声部统计两组材料的半音与大跳占比，差别是否明显。只听固定音型，再逐层加回持续低音、铺底与重击，听分量来自哪一层。把循环体结尾直接接回循环起点，听属到主的接缝与小节线。逐个触发打倒一个敌人、复活、放大招、大招被打断、残血换曲，听进出是否落在合适的拍点；残血循环连放三四轮，听有没有回落感。

**补充可交付内容。**材料来源表（来源、含义、借哪一句、怎么变奏），两组材料的音程统计，段落与循环体表，事件规则表（大招静音、残血换曲、按出场者切段的触发、等待与入口），以及固定音型与谢泼德循环的音名草稿。

**具体材料与场景。**《囿于棋格中》四分音符约 139、4/4；《方寸颠倒》约 121。鉴赏者在 OST 文件上打了段落标记：第一首 B 约 0:32、C 0:49、B′ 1:16、A′ 1:40、猫 2:01，循环点 2:24（跳回 0:32），循环体 65 小节；第二首 B 约 0:18、A′ 0:42、B′ 1:02、侏儒小尾巴 1:18、新旋律 1:26、开头那句 1:39（约 1:46 突然转自然大调）、魔女会动机 2:01、男女主唱 2:17、猫 2:41、尾奏 2:49。第一首由乐器主奏；第二首由男女高音二人唱跳着的“哈”，没有歌词。第二首的侏儒动机比第一首低小三度，猫的主题高半音。动机出处是鉴赏者“可能借鉴”的判断，魔女会主题未逐音核对。玩家钢琴改编版只有第 2–62 小节可当原曲缩谱：第 1 小节的琶音开头、第 63 小节以后的展开、再现与大调结尾都是改编者写的。

## G06：让戏曲唱段同时满足歌词与戏剧任务

**创作目标。**以《八奇炼桃都》相关唱段为参照，在角色叙事中组织原创旋律、传统戏曲素材与歌词表达。

**做法。**

1. 确认唱段的戏剧动作、长度和必须突出的歌词。
2. 选择所需的唱腔基础与融合方向，例如河北梆子、昆曲或京剧中的具体旋律和行腔特征，避免只依靠乐器音色表示风格。
3. 若采用西皮流水等传统素材，分别标明素材、填词、改写和原创段落的范围。
4. 先念歌词再写旋律，检查重音、声调走向和关键字的可懂度。
5. 通过试唱修订倒字、咬字或行腔不自然的地方；不熟悉的语言和剧种交由熟悉者核验。

**检查。**不看文字是否仍能听懂重点歌词，旋律是否符合所选风格，融合是否有具体依据。声调与歌唱的关系应结合语言和唱腔处理，不机械逐点复制说话的音高曲线。

**可交付内容。**唱段结构、歌词重点、旋律草稿、素材分工及试唱修订记录。

**具体材料与场景。**区分约一分钟的过场动画原创唱段与采用传统西皮流水组织的段落。前者从歌词和画面时长写起，可分析河北梆子、昆曲及京剧的融合；后者应明确具体唱段、填词和行腔。西皮流水是板式名称，不能只凭这个名称还原一首固定旋律。不要将相同演唱者参与的不同作品互相替换。

## G07：用管弦乐编制实现清楚的音乐表达

**创作目标。**以《原神》中的管弦乐表达为参照，在保持旋律清楚、结构可感的同时，利用丰富音色塑造层次。

**做法。**

1. 先确定音乐语言与结构，再选编制；使用管弦乐队不自动限定曲式或和声风格。
2. 完成主旋律、低音与基本和声，明确各声部承担的作用。
3. 将旋律、和声支撑、节奏和对位分配到合适的乐器、音区与力度层次。
4. 主旋律不清楚时，先检查同音区的密度、持续时间、音色与力度，再选择改配器或混音处理。

**检查。**较少声部时的主题是否成立，增加乐器后是否更好地服务于目标，每个声部是否都有保留理由。不要用更厚的织体掩盖不明确的旋律与结构。

**可交付内容。**段落配器表、主次关系与修改前后的比较。练习见 [练习六](practice-patterns.md)。

**制作落地。**先用 MIDI 记录旋律、低音和内声部，再根据功能选择采样或合成音色。采样音色需校验演奏法、力度变化和实际音区；合成音色需校验起音与延音是否改变节奏或遮住主旋律。声部音量与力度可以在编配阶段建立平衡；音区安排、演奏与后期处理各自承担不同工作，不能将它们视为可完全互换的参数。这些是制作练习的实现步骤，参数随素材判断。

## G08：用很少的材料长出一首可循环的战斗曲

**创作目标。**以《原神》霜月战斗曲《寂夜月如锋》为参照，写一首约三分钟、持续往前推、段落整齐、能在游戏里循环的战斗曲，让整首听起来出自同一组材料。参照曲的性格是明亮、漂浮，不是宏大。参照有三份：一位 up 主的人工鉴赏，段落、调性、性格与配器以它为准；玩家逐音扒谱、用钢琴音源做的还原版，音高、和声与节拍可当原曲缩谱来读；原版录音，响度、频段与声像来自分段实测。钢琴版里的同音反复、滚动低音、八度叠高是扒谱者把乐队缩到钢琴上的处理，响度也只反映钢琴版。

**做法。**

1. 先写核心动机和律动：四个音、两小节内就能认出，例如用两个方向相反的纯四度跳进，既清新又有弹性。十六分音符按 3+3+3+3+2+2 分组：前面四组三音让重音和小节线错开，最后两对让重音落回拍子，接进下一小节的第一拍。开头让它单独响一两小节，再逐层加入低音持续音和内声部。速度本身不必很快，推力来自分组和反拍切分。
2. 让主旋律从动机里长出来：取动机尾部的级进当旋律，先在前奏各小节的尾巴里按旋律将走的顺序逐级预告，再正式陈述。旋律用调内模进每两小节上移一级，顶点留一个色彩音。
3. 新段落优先从已有材料里取：把一直在背景里打的脉动推到前景，当新主题的中心音；动机回归时换一个低音，同一组音就有新的和声意义；高潮不另写新旋律，把两三种已出现的材料叠在一起。分清旋律和伴奏音型：钢琴的级进琶音、加花再显眼，也是伴奏，不当新动机来发展。
4. 旋律重复时换主奏乐器，伴奏音型在声部之间交换；相邻两段至少留一层上一段的元素。简短的琶音可以反复用，每次换乐器或节奏。
5. 段落整齐、组内起伏：每段 8 小节，几段组成一个段落组，组内先放下来、再推两次（“一加二”），一组约 30～50 秒，下一组的高峰比上一组略高。每段换一个音区中心；积蓄段可以压到低音区，清空高频。
6. 定一种和声色彩并守住它：要明亮而漂浮，用大调的音，收束多走 IV–V–vi、少落主和弦，多用挂留与空五度；和声节奏一到两小节，多用持续音；色彩和弦留给关键位置，各用一次。同一组音也能读成关系小调，明暗不同，先用低音、收束与乐句落音定下调性中心。
7. 升调前先蓄力：上一段先稳住，下一段旋律密度翻倍，加三连音琶音这类节奏变化；旋律与低音最后都半音上行，直接落到新调主音。进入新调后先抽掉一层低音、降低密度，再逐步建回。
8. 结尾服从用途：参照曲停在新调的 vi 上，只留一两件乐器，加混响与延迟淡出，不做完满终止。需要接回开头时另写接缝，见练习十三。

**配器。**乐器名称以人工鉴赏为准；响度、频段、声像与敲击层来自原版录音的分段实测，并与钢琴扒谱逐小节对齐。

1. 编制服从性格：参照曲只用弦乐、钢琴、长笛与短笛，加合成器，没有铜管和打击乐。旋律交给长笛、短笛、大提琴、高音弦乐和合成器这类高音或明亮的乐器，律动交给低音弦乐；层次再多，每个声部都听得清。
2. 前奏由钢琴弹动机，短笛与合成器只叠在重音上，另有一层密集的敲击声；弦乐打均匀的八分音符。约每两小节进一层，十小节内响度抬高约 8 dB。
3. 低谷保持同样深度，高峰逐级抬高：前奏之后，各段落组的第一段响度相近，每组最后一段比上一组的高峰略高，终段最高。抬高峰靠加层、换主奏和敲击层回归，不靠推子；去掉前奏和尾奏，各段只差约 6 dB。
4. 十六分音符的高频敲击层当密度开关：高能段用均匀的十六分音符；积蓄段和刚转调时关掉，或退成八分音符。没有流行式的反拍鼓组，重音跟着动机分组、旋律或低音的切分走。
5. 积蓄段“清空高频、留重低音”：1 kHz 以上几乎清空，中音区留钢琴和弦，低音律动加重；能量降下来，推进不断。
6. 低音弦乐逐段加密：从一小节一下，到 3+3+2 的律动，再到稳定密集的八分音符。
7. 段落接缝用“高频逐拍变亮 → 低频重拍”：上一段最后两小节让高频能量逐渐抬起，下一段第一拍用低频落地。做亮的是哪件乐器，鉴赏没有讲，按项目自选。
8. 低音居中、高频铺宽；转调后的段落最宽、最开阔。
9. 留意 60～600 Hz：参照曲有两段 60–250 Hz 占到一半以上。需要给主旋律或游戏音效留位置时，先改这些层的音区与时值。

**检查。**为每段标出材料来源（核心动机、动机尾部、背景脉动、已有材料叠加或新材料），确认衍生关系听得出来，同时判断是否还需要一段真正的对比材料。只留动机和低音时，推进感是否仍成立。按段落组列出各段响度，确认低谷相近、高峰逐组抬高；终段要比前面的高峰更大时，确认留出了前面没用过的音区或层，而不是只加音量。旋律换主奏后，是否仍认得出是同一条。升调前后各听两小节，检查蓄力与落点。关掉高频敲击层、清空高频之后，积蓄段是否仍有推进；每层叠上去后，是否听得出它负责的那部分。需要循环时，把结尾直接接回开头，听接缝。

**可交付内容。**材料谱系表、段落组与音区中心表、主奏轮换表、升调路线与结尾（或循环接缝）的和弦及低音、层的进出表，以及动机、预告与陈述的音名草稿。练习见 [练习十一至十五](practice-patterns.md)。

**具体材料与场景。**参照曲为四分音符 = 125、4/4，A 大调，第 68 小节升半音到降 B 大调；同样的音也能读成升 F 小调转 G 小调，但收束、唯一一次属到主与人工鉴赏都支持大调读法。核心动机是 E、B、C♯、F♯（5 2 3 6）。全曲 12 段，每段 8 小节（前奏多两小节，尾奏两小节），段落组为 A（前奏与两遍主题一）、B（主题二与两遍主题三）、C（两遍主题四）、B（升半音再现）。前奏动机的尾巴预告主题一旋律的三级台阶；主题二的中心音来自前奏内声部的八分音符脉动；转调前的第 64–65 小节是钢琴的八分音符三连音琶音；转调后显眼的五音级进下行是钢琴的伴奏琶音；主题三第三遍的后半（第 80–83 小节）同时复现主题三与前奏旋律。按半小节识别的和弦近六成没有三音；色彩和弦 V/V（带升四级）与 ♭VII 各出现一次；落到主和弦的属到主只有转调前一次（E → A）。结尾停在新调的 vi（G）上，尾奏只剩钢琴与短笛，最后一个音是 D，混响与延迟淡出；原版录音一进尾奏，低频在一秒内掉 20 dB 以上，约 9 秒淡完。原曲在游戏中的循环点未核对。不要从钢琴版的响度推断原曲的起伏：原版录音后三个段落组的第一段约 −14.6～−15.0 LUFS，四组高峰依次约 −12.6、−11.7、−10.1、−9.2 LUFS；积蓄段（主题四①）20–60 Hz 约占三分之一，1–4 kHz 只占 3%。乐器名称以人工鉴赏为准：听音模型报过的圆号、小号、定音鼓、太鼓与合唱都和鉴赏矛盾，不采纳。

## 通用场景：战斗强度的分层变化

用稀疏节奏或氛围提示潜在危险，战斗升级时加入低音、和声、主题或对位，强烈状态再加入强调声部。让每个允许的组合都成立，明确加入与退出的音乐位置。

状态变化既可以通过层的增减实现，也可以通过换段实现。先确定要改变的是密度、旋律内容、和声张力还是结构，再选择控制方式，避免所有状态都只改变音量。
